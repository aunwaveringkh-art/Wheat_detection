# Model Card: Детектор колосьев пшеницы (Wheat Detection)

## 1. Model Details (Детали модели)
*   **Разработчик:** В рамках учебного/практического проекта Wheat_detection.
*   **Тип модели:** Сверточная нейронная сеть для детекции объектов (Object Detection).
*   **Архитектура:** YOLOv8n (You Only Look Once, версия 8, нано-вариант). Легковесная модель, оптимизированная для быстрого инференса на CPU и GPU.
*   **Версия:** 1.0.0 (исходные веса `models/best.pt`).
*   **Фреймворк:** Ultralytics YOLOv8, PyTorch.

## 2. Цели создания проекта и бизнес-контекст
*   **Проблема:** Традиционный подсчет колосьев пшеницы на фотографиях поля — это трудоемкий, субъективный и медленный процесс. Агрономы вынуждены вручную просматривать тысячи снимков с дронов, что занимает дни и приводит к ошибкам из-за усталости глазомера.
*   **Цель:** Автоматизировать процесс детекции и подсчета колосьев, предоставив агроному инструмент для быстрой и объективной оценки плотности посевов. Это позволяет оперативно выявлять проблемные зоны, прогнозировать урожайность и принимать решения о внесении удобрений.
*   **Почему ML:** Классические алгоритмы компьютерного зрения плохо справляются с плотными сценами, где колосья перекрывают друг друга, имеют разный размер, цвет и ориентацию. Сверточные нейросети (YOLO) обучены выделять признаки объектов в сложных условиях, что делает их идеальным инструментом для этой задачи.

## 3. Intended Use (Предполагаемое использование)
*   **Основное использование:** Автоматическое обнаружение и подсчет колосьев пшеницы на фотографиях поля для оценки урожайности и анализа состояния посевов.
*   **Нецелевое использование:** Модель не предназначена для определения болезней растений, классификации сортов пшеницы, оценки стадии зрелости или для работы с изображениями, где колосья не являются доминирующим объектом (например, городские пейзажи, интерьеры).

## 4. Factors (Факторы)
На качество предсказания модели могут влиять следующие факторы:
*   **Освещение:** Сильные тени или пасмурная погода могут снизить точность детекции.
*   **Ракурс и высота съемки:** Модель может быть чувствительна к углу обзора дрона. Снимки, сделанные строго сверху, могут отличаться от снимков под углом.
*   **Зашумленность:** Наличие плотного сорняка, других культур или объектов (например, камней) может привести к ложным срабатываниям.
*   **Разрешение:** Из-за масштабирования до 640x640 очень мелкие колосья на исходных фотографиях высокого разрешения могут быть не обнаружены.
*   **География и сорт:** Модель может быть чувствительна к сортам пшеницы, произрастающим в разных климатических зонах. В датасете представлены Европа и Северная Америка, поэтому для других регионов может потребоваться дообучение.

## 5. Metrics (Метрики)
Для оценки качества модели используются стандартные метрики детекции объектов:
*   **Precision (Точность):** Доля верных срабатываний (сколько из найденных объектов действительно являются колосьями). Важна, чтобы не переоценить урожайность из-за ложных объектов.
*   **Recall (Полнота):** Доля найденных объектов (сколько реальных колосьев модель смогла найти). Важна, чтобы не пропустить реальные колосья и не занизить урожайность.
*   **mAP (Mean Average Precision):** Основная метрика, учитывающая точность определения координат (bounding box) и уверенность модели.
*   **mAP50:** Средняя точность при IoU=0.5 (мягкий порог).
*   **mAP50-95:** Средняя точность при IoU от 0.5 до 0.95 (строгий порог, показывает, насколько точно модель очерчивает рамки).

## 6. Evaluation Data (Данные для оценки)
*   **Датасет:** Исходный набор данных, на котором проводилась валидация (см. `reports/baseline/`).
*   **Примечание:** В исходной версии проекта валидация проводилась на тех же изображениях, что и обучение. Это может приводить к завышенным метрикам. Для получения честных результатов необходимо переобучение после команды `split-data` (разделение на train/val).

## 7. Training Data (Данные для обучения)
*   **Источник:** Публичный датасет из соревнования **Global Wheat Detection** на платформе Kaggle: [https://www.kaggle.com/c/global-wheat-detection](https://www.kaggle.com/c/global-wheat-detection).
*   **О датасете:** Набор данных был собран консорциумом из девяти исследовательских институтов из семи стран (Университет Токио, INRAE, Arvalis, ETHZ, Университет Саскачевана, Университет Квинсленда, Нанкинский сельскохозяйственный университет, Rothamsted Research и др.). Это гарантирует высокое качество и разнообразие разметки.
*   **Состав данных:** Обучающая выборка содержит более 3000 изображений из Европы (Франция, Великобритания, Швейцария) и Северной Америки (Канада). Тестовая выборка (около 1000 изображений) включает данные из Австралии, Японии и Китая.
*   **Особенности разметки:** Изображения размечены для задачи детекции объектов (bounding boxes). Оценка в соревновании проводилась по метрике mAP при различных порогах IoU (от 0.5 до 0.75).
*   **Параметры обучения в нашем проекте:** 50 эпох, размер батча (batch) 16, разрешение изображений 640x640. Использовалась предобученная модель YOLOv8n (transfer learning).

## 8. Quantitative Analyses (Количественный анализ)
Согласно данным из `reports/baseline/`, исходная модель YOLOv8n показала следующие результаты:

| Метрика | Значение | Описание |
| :--- | :--- | :--- |
| **Precision** | 0.930 | Точность (доля верных срабатываний) |
| **Recall** | 0.907 | Полнота (доля найденных объектов) |
| **mAP50** | 0.964 | Средняя точность при IoU=0.5 |
| **mAP50-95** | 0.607 | Средняя точность при IoU от 0.5 до 0.95 |

> **Примечание:** Метрики могут быть завышены из-за валидации на обучающей выборке. Для честной оценки необходимо переобучение после `split-data`.

## 9. Ethical Considerations (Этические соображения)
*   **Предвзятость:** Модель может быть предвзята к определенным регионам, если обучалась на данных только из одного места. Рекомендуется валидация на данных из целевого региона.
*   **Ограничение по сортам:** Модель не различает сорта пшеницы, поэтому ее использование для точной оценки урожайности конкретного сорта может быть ограничено.
*   **Влияние на труд:** Модель автоматизирует рутинный процесс подсчета, что может изменить обязанности агронома (смещение фокуса с ручного труда на анализ данных). Это не замена, а инструмент поддержки принятия решений.

## 10. Caveats and Recommendations (Ограничения и рекомендации)
*   **Одиночный класс:** Модель детектирует только колосья пшеницы. Она не различает стадии зрелости или болезни растений.
*   **Производительность:** Благодаря архитектуре YOLOv8n, модель обеспечивает высокую скорость работы, в том числе на CPU, что позволяет использовать её на полевых ноутбуках без мощной видеокарты.
*   **Рекомендация по данным:** Для повышения качества на новых регионах рекомендуется дообучение на локальных данных (fine-tuning).
*   **Порядок использования:** Для запуска инференса используется команда `poetry run wheat-detection predict путь/к/фото.png`.
